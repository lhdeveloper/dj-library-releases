# DJ Library

**Sua biblioteca de DJ em ordem, do download ao rekordbox.** App para macOS.

Achar a versão certa da faixa, preencher BPM, tom e gênero, separar em pastas e montar as playlists do rekordbox costuma ser trabalho manual, faixa por faixa. O DJ Library faz isso por você:

1. **Busca e ouve**: artista, faixa e mix (ou um link do YouTube ou SoundCloud). Ouça a prévia antes de baixar.
2. **Baixa pronto para tocar**: MP3 320 kbps com capa, gênero, BPM e tom (Camelot) nas tags.
3. **Organiza as pastas**: cada faixa vai para Ano › Mês › Gênero, reaproveitando as pastas que você já tem. A barra lateral mostra as pastas como no Finder.
4. **Coloca no rekordbox**: direto nas suas playlists, no seu padrão, em ordem de tom. Sem XML. Com backup antes e só com o rekordbox fechado.

Baixe só o que você tem direito de baixar.

## Instalar

1. Baixe o `.dmg` da [versão mais recente](https://github.com/lhdeveloper/dj-library-releases/releases/latest).
2. Abra o `.dmg` e arraste o **DJ Library** para **Aplicativos**.
3. Na primeira vez, clique com o botão direito no app e escolha **Abrir** (o app não é distribuído pela App Store).
4. Instale as ferramentas de áudio pelo [Homebrew](https://brew.sh), no Terminal:

   ```
   brew install yt-dlp ffmpeg libkeyfinder
   ```

Requer macOS 15 ou mais novo.

## Atualizações

Quando sai uma versão nova, aparece o botão **Atualizar** no topo do app. Ele mostra as novidades, baixa, instala e reabre o app sozinho.
